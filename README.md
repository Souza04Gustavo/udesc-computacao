# Repositório de Materiais da Graduação em Ciência da Computação - UDESC

Este repositório contém materiais, trabalhos, notas de aula e projetos desenvolvidos durante minha graduação em Ciência da Computação na UDESC (Universidade do Estado de Santa Catarina). Vale ressaltar que essas não são todas as matérias do curso pois algumas como as do departamento de matemática só possuem exercícios e provas em papel portanto não foi permitido/produtivo registrar as ações. Além disso algumas matérias eu criei repositório pessoal na minha conta ou de amigos para gerir melhor o conteúdo/trabalho.
